# Hint Images Folder

Place all your hint images in this folder.

## Naming Convention

Use simple, descriptive names for your hint images:

- `hint1.jpg` or `hint1.png`
- `hint2.jpg` or `hint2.png`
- `hint3.jpg` or `hint3.png`
- `hint4.jpg` or `hint4.png`
- `hint5_final.jpg` or `hint5_final.png` (for the final hint)

## Supported Formats

- `.jpg` / `.jpeg`
- `.png`
- `.gif`
- `.webp`

## Access URL

Images will be accessible at:
`http://localhost:5000/hints/hint1.jpg`

When setting up hints in the database, use the path relative to this folder:

- `hint1.jpg`
- `hint2.png`
- etc.

## Image Guidelines

- **Resolution**: Recommended minimum 800x600px
- **File Size**: Keep under 2MB for faster loading
- **Content**: Ensure images are clear and provide good visual clues
- **Format**: PNG for graphics with text, JPG for photos
